You do not need all of these. Pick **one primary track** and use the others to fill gaps. Each entry says what it is best for. Links were checked when this course was built; sites move, so if one breaks, search the title.

## How to choose

| If you want to… | Start with |
|---|---|
| Build apps with LLMs quickly | provider docs and cookbooks, DeepLearning.AI short courses, Hugging Face courses |
| Understand how models work, from scratch | Karpathy lectures, Raschka's book, Stanford CS336/CS224N |
| Learn evals and production practice | Applied LLMs, Hamel Husain's writing, Chip Huyen's book |
| Get strong foundations in ML and maths | Ng's specialisation, fast.ai, 3Blue1Brown, Understanding Deep Learning |
| Prepare for interviews | this course's Career module, Huyen's books, system-design reading |

## Hands-on courses (build things)

- [Hugging Face LLM Course](https://huggingface.co/learn/llm-course) — Transformers, fine-tuning, datasets, tokenizers with runnable notebooks. Free.
- [Hugging Face Agents Course](https://huggingface.co/learn/agents-course) — agent concepts, frameworks and a final project. Free.
- [Hugging Face MCP Course](https://huggingface.co/learn/mcp-course) — build and use Model Context Protocol servers and clients. Free.
- [Hugging Face Cookbook](https://huggingface.co/learn/cookbook) — task-focused recipes (RAG, evals, fine-tuning, multimodal). Free.
- [DeepLearning.AI short courses](https://www.deeplearning.ai/short-courses/) — one- to two-hour courses on RAG, agents, evals, fine-tuning with industry partners. Mostly free.
- [Anthropic courses (GitHub)](https://github.com/anthropics/courses) — API fundamentals, prompt engineering, evaluations and tool use as notebooks. Free.
- [Claude docs: prompt engineering overview](https://docs.claude.com/en/docs/build-with-claude/prompt-engineering/overview) — a practical, example-rich guide. Free.
- [OpenAI Cookbook](https://cookbook.openai.com) — worked examples for APIs, retrieval, evals and agents. Free.
- [Microsoft: Generative AI for Beginners](https://github.com/microsoft/generative-ai-for-beginners) — 21 lessons with code. Free.
- [Cohere LLM University](https://cohere.com/llmu) — embeddings, search, RAG and text generation. Free.
- [Pinecone Learning Center](https://www.pinecone.io/learn/) — vector search, RAG and retrieval explainers. Free.
- [LangChain Academy](https://academy.langchain.com) — LangGraph and agent-building courses. Free.
- [Full Stack LLM Bootcamp](https://fullstackdeeplearning.com/llm-bootcamp/) — application-focused lectures on prompting, UX, tooling and deployment. Free.
- [Made With ML](https://madewithml.com) — production ML engineering: testing, CI/CD, MLOps. Free.

## University lectures (understand deeply)

- [Stanford CS336: Language Modeling from Scratch](https://stanford-cs336.github.io/spring2025/) — build a language model end to end: tokenisation, architectures, training, systems, scaling, alignment. Demanding and excellent.
- [Stanford CS224N: NLP with Deep Learning](https://web.stanford.edu/class/cs224n/) — the standard NLP course through transformers and LLMs.
- [Stanford CS25: Transformers United](https://web.stanford.edu/class/cs25/) — guest lectures from researchers on transformer frontiers.
- [Stanford CME295: Transformers and LLMs](https://cme295.stanford.edu/) — a focused course on how modern LLMs work.
- [fast.ai: Practical Deep Learning for Coders](https://course.fast.ai) — top-down deep learning with code first.
- [Coursera: Machine Learning Specialization (Andrew Ng)](https://www.coursera.org/specializations/machine-learning-introduction) — classic ML foundations.

## Video series and visual explainers

- [Andrej Karpathy: Neural Networks, Zero to Hero](https://karpathy.ai/zero-to-hero.html) — build backprop, a language model, GPT and a tokenizer from scratch. The best single starting point for fundamentals.
- [3Blue1Brown: Neural networks](https://www.3blue1brown.com/topics/neural-networks) — beautifully visual explanations, including transformers and attention.
- [The Illustrated Transformer (Jay Alammar)](https://jalammar.github.io/illustrated-transformer/) — the classic visual walk-through.
- [Lilian Weng's blog](https://lilianweng.github.io) — long-form, rigorous overviews (prompting, agents, attention, diffusion, reward hacking).
- [Stanford Online on YouTube](https://www.youtube.com/@stanfordonline) — full lecture recordings of Stanford AI courses.

## Books

| Book | Best for |
|---|---|
| [AI Engineering (Chip Huyen)](https://www.oreilly.com/library/view/ai-engineering/9781098166298/) | the most complete treatment of building applications on foundation models: evals, RAG, agents, fine-tuning, inference, architecture |
| [Build a Large Language Model From Scratch (Sebastian Raschka)](https://github.com/rasbt/LLMs-from-scratch) | implementing a GPT-style model and fine-tuning it step by step (code is free on GitHub) |
| [Hands-On Large Language Models (Alammar and Grootendorst)](https://www.oreilly.com/library/view/hands-on-large-language/9781098150952/) | visual, practical introduction to tokens, embeddings, search, fine-tuning |
| [Natural Language Processing with Transformers (Tunstall, von Werra, Wolf)](https://www.oreilly.com/library/view/natural-language-processing/9781098136789/) | Hugging Face ecosystem and transformer fine-tuning |
| [Designing Machine Learning Systems (Chip Huyen)](https://www.oreilly.com/library/view/designing-machine-learning/9781098107957/) | production ML thinking: data, deployment, monitoring |
| [Designing Data-Intensive Applications (Martin Kleppmann)](https://dataintensive.net) | the systems fundamentals behind any scalable backend |
| [Speech and Language Processing (Jurafsky and Martin)](https://web.stanford.edu/~jurafsky/slp3/) | free, comprehensive NLP textbook, updated for LLMs |
| [Dive into Deep Learning](https://d2l.ai) | free interactive deep-learning textbook with code |
| [Understanding Deep Learning (Simon Prince)](https://udlbook.github.io/udlbook/) | free, modern, clearly illustrated deep-learning text |
| [Mathematics for Machine Learning](https://mml-book.github.io) | free maths foundations (linear algebra, calculus, probability) |

## Suggested combinations

**Fast path for software engineers (about 6 weeks):** this course's Foundations, LLM APIs, RAG, Agents, Evals modules, plus DeepLearning.AI short courses on topics you want to see from another angle, and Applied LLMs for judgement.

**Deep understanding path (about 3 months):** Karpathy's Zero to Hero, then Raschka's book, then selected CS336 lectures; in parallel, build one RAG and one agent project with evals.

**Applied scientist path:** Huyen's AI Engineering book, CS224N/CS336 for foundations, and a fine-tuning project using Hugging Face TRL.

## Using a course well

- **Do the exercises**; watching alone creates an illusion of understanding.
- **Build one project per course** on your own data.
- **Skim, then deepen**: start with an overview and return to detailed lectures when a project demands it.
- **Mix sources**: one structured course for sequence, plus blogs and papers for freshness.

```quiz
? Which resource is best for building a GPT-style model from scratch with code?
+ Karpathy's Zero to Hero or Raschka's Build a Large Language Model From Scratch

```
