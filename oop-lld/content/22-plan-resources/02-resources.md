You do not need many resources. These are the few worth keeping open. Every link below was checked when this course was built.

## References for C++

:::resources
- [cppreference.com](https://en.cppreference.com/w/) — the standard reference for the language and library. Look up any function, its complexity and examples.
- [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines) — rules from Bjarne Stroustrup and Herb Sutter on modern, safe C++. Great for "why" answers.
- [learncpp.com](https://www.learncpp.com/) — a free, patient tutorial if a basic topic feels shaky.
- [isocpp.org FAQ](https://isocpp.org/faq) — answers to the questions interviewers love.
- [Guru of the Week](https://herbsutter.com/gotw/) — Herb Sutter's short exception safety and design puzzles.
:::

## Tools to experiment with

:::resources
- [Compiler Explorer](https://godbolt.org/) — compile and run C++ in the browser, see assembly and try compilers (the course runner uses it for edited code).
- [C++ Insights](https://cppinsights.io/) — shows what the compiler really does (lambdas, range-for, implicit conversions).
- [Quick Bench](https://quick-bench.com/) — benchmark two versions of a snippet.
:::

## Design patterns and LLD

:::resources
- [Refactoring Guru: design patterns](https://refactoring.guru/design-patterns) — clear explanations with diagrams.
- [Refactoring Guru: refactoring](https://refactoring.guru/refactoring) — the smells and refactorings used in the drills lesson.
- [SourceMaking: design patterns](https://sourcemaking.com/design_patterns) — another set of explanations and anti-patterns.
- [Awesome Low Level Design (GitHub)](https://github.com/ashishps1/awesome-low-level-design) — a community list of LLD problems to practise.
:::

## Books worth owning

| Book | Why |
|---|---|
| *A Tour of C++* (Bjarne Stroustrup) | a short, modern tour by the language's creator ([author page](https://www.stroustrup.com/tour3.html)) |
| *The C++ Programming Language* (Bjarne Stroustrup) | the deep reference ([author page](https://www.stroustrup.com/4th.html)) |
| *Effective Modern C++* (Scott Meyers) | 42 items on C++11 and C++14 pitfalls |
| *Design Patterns* (Gamma, Helm, Johnson, Vlissides) | the original patterns catalogue |
| *Head First Design Patterns* | friendly introduction to the patterns |
| *Clean Code* and *Clean Architecture* (Robert C. Martin) | SOLID and structure at scale |
| *Refactoring* (Martin Fowler) | the refactoring catalogue |
